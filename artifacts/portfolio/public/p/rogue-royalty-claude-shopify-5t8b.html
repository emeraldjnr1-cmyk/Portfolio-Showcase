Pain 01

Shopify shows sales, conversion and order value, but not why a week went up or down. Working that out means jumping between reports and comparing date ranges by hand.

Your harness and leather collar collections compete with other pages for the same searches. Without a side-by-side comparison, it is hard to know which fix to do first.

Cost today: effort spent on changes that move nothing, while the high-impact fixes wait.

05 · How the work runs

Read first, write later.

Claude reads your store through an MCP server backed by a Shopify custom app token with read-only scopes. The dashboard reads the same data on a schedule, so Claude and the dashboard always agree.

How the figures are checked

Same range, same time zone, same definitions as Shopify.

  • Same date range and store time zone as your Shopify Analytics report, so no order lands in the wrong day
  • Shopify's own definitions: net sales after discounts and returns, conversion from Shopify's sessions, test orders excluded
  • Full order history: Shopify only shares the last 60 days by default, so older orders are requested separately for week-on-week and year-on-year
  • A variance table for each metric, dashboard against Shopify, with every gap explained line by line
  • Milestone 1 is released only once you have seen the three metrics match
